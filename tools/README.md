# 工具脚本目录

本目录存放项目开发和维护过程中使用的辅助工具脚本。

## 工具分类

### 🔧 数据工具
- 地址提取和验证
- 密钥生成和转换
- 数据格式化工具

### 📊 分析工具
- 性能基准测试
- 日志分析工具
- 数据可视化工具

### 🛠️ 开发工具
- 代码质量检查
- 文档链接验证
- 配置管理工具

### 🚀 部署工具
- SSH配置脚本
- 远程推送脚本
- 环境设置工具

## 使用规范

1. **脚本命名**：使用小写字母和下划线，如 `extract_addresses.py`
2. **文档要求**：每个脚本应包含使用说明和示例
3. **依赖管理**：如需要额外依赖，在脚本开头注明
4. **清理原则**：不再使用的工具应及时删除
