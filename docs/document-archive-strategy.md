### 方案1: 创建archive目录（推荐）

```text

├── import-path-final-optimization-report.md  # 保留在主目录
└── archive/
```

**优点**:

## 未来文档管理指南

### 新文档创建原则

1. **单一真相源**: 每个主题只保留一个主要文档
2. **版本更新**: 更新现有文档而非创建新文档
3. **历史版本**: 重大变更时保留历史版本到archive/
4. **文档索引**: 相关文档创建INDEX.md

### 文档分类

```bash
docs/
├── *.md                    # 当前有效文档
├── archive/                # 历史归档
│   └── YYYY-MM-DD_topic/   # 按日期和主题组织
│       └── INDEX.md
└── templates/              # 文档模板
```

### 归档触发条件

- ✅ 文档被新版本替代
- ✅ 多个文档内容重叠>50%
- ✅ 阶段性工作完成（如重构项目）
- ✅ 维护成本过高
