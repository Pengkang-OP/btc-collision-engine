## ✅ 修复摘要

### 问题描述

P1-2: 私钥数据泄露到日志和内存

**修复前** ❌:

```python
# 问题1: 日志中记录私钥前缀
message=f"检测到重复的私钥: {private_key[:16]}...",
details={'private_key_prefix': private_key[:16]}

# 问题2: 内存中存储明文私钥
stats['seen_keys'].add(private_key)  # 明文存储
```

**修复后** ✅:

```python
# 使用SHA256哈希代替明文
private_key_hash = hashlib.sha256(
    private_key.encode() if isinstance(private_key, str) else private_key
).hexdigest()

# 问题1修复: 日志中只记录哈希前缀
message=f"检测到重复的私钥: hash={private_key_hash[:8]}...",
details={'private_key_hash_prefix': private_key_hash[:8]}

# 问题2修复: 内存中存储哈希
stats['seen_keys'].add(private_key_hash)  # 哈希存储
```

| 属性 | 说明 |
|------|------|
| **哈希算法** | SHA-256 (SHA-2家族) |
| **输出长度** | 256位 (64位十六进制) |
