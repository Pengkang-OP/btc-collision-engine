## 🔴 严重问题 (Critical)

### 1. **缺少路径遍历安全检查**
**位置**: `import_addresses` 方法，第395行  
**问题**: 直接使用 `source_path` 而没有进行路径遍历安全检查  
**风险**: 攻击者可能通过 `../` 等路径遍历攻击读取系统敏感文件  

**当前代码**:
```python
if not os.path.exists(source_path):
    result['error'] = f"源文件不存在: {source_path}"
    return result
```

**对比项目标准** (`resolver.py` 第305-314行):
```python
# 安全检查: 防止路径遍历攻击
real_path = os.path.realpath(filepath)
allowed_dirs = [
    os.path.abspath(os.getcwd()),
    os.path.abspath(os.environ.get('TEMP', '/tmp')),
    os.path.abspath(os.environ.get('TMP', '/tmp')),
]
if not any(real_path.startswith(allowed_dir) for allowed_dir in allowed_dirs):
    logger.error(f"安全警告:路径遍历攻击检测 - 路径超出允许范围: {real_path}")
    return addresses
```

**建议修复**:
```python
# 安全检查: 防止路径遍历攻击
real_source_path = os.path.realpath(source_path)
allowed_dirs = [
    os.path.abspath(os.getcwd()),
    os.path.abspath(os.environ.get('TEMP', '/tmp')),
    os.path.abspath(os.environ.get('TMP', '/tmp')),
]
if not any(real_source_path.startswith(allowed_dir) for allowed_dir in allowed_dirs):
    result['error'] = f"安全警告: 路径超出允许范围"
    logger.error(f"安全警告: 路径遍历攻击检测 - 路径={real_source_path}")
    return result

if not os.path.exists(real_source_path):
    result['error'] = f"源文件不存在: {source_path}"
    return result
```

### 5. **CSV头部检测逻辑不够健壮**
**位置**: `_read_csv_source` 方法，第521-526行  
**问题**: 头部检测仅基于地址前缀，可能误判  

**当前代码**:
```python
if not header_skipped:
    # 检查是否是头部行
    if row and not row[0].startswith('1') and not row[0].startswith('3') and not row[0].lower().startswith('bc1'):
        header_skipped = True
        continue
    header_skipped = True
```

**问题场景**:
- 如果第一行是注释 `# addresses` 会被当作数据
- 如果CSV没有头部且第一个地址恰好不符合预期格式会出错

**建议修复**:
```python
header_skipped = False
for row in reader:
    if not row:  # 跳过空行
        continue
        
    if not header_skipped:
        # 更健壮的头部检测
        first_cell = row[0].strip().lower()
        is_header = (
            first_cell in ('address', 'addresses', 'addr', 'target', 'targets') or
            first_cell.startswith('#') or
            not (first_cell.startswith('1') or first_cell.startswith('3') or first_cell.startswith('bc1'))
        )
        if is_header:
            header_skipped = True
            continue
        header_skipped = True
    
    if row[0].strip():
        addresses.append(row[0].strip())
```
