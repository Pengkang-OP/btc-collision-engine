### 自动刷新机制

```python
def _start_auto_update(self):
    """启动自动更新(每5秒)"""
    self._refresh_alerts()
    self._update_job = self.after(5000, self._start_auto_update)
```

**特点**:

- ✅ 非阻塞 (使用Tkinter after)
- ✅ 自动循环
- ✅ 可取消 (destroy时)
