## 🎯 使用场景推荐

### 场景1: 个人研究（单机）

**推荐方案**: systemd服务

**理由：**

- 性能开销最小
- 系统级集成
- 长期稳定运行

**部署命令：**

```bash
sudo bash deploy/install-systemd.sh
```

---

### 场景2: 团队开发（多环境）

**推荐方案**: Docker Compose

**理由：**

- 环境一致性
- 快速部署和迁移
- 多版本共存

**部署命令：**

```bash
# 开发
docker-compose --profile cpu up -d

# 测试
docker-compose --profile gpu up -d
```

---

### 场景3: 大规模生产（多节点）

**推荐方案**: Docker Swarm / Kubernetes

**理由：**

- 横向扩展
- 负载均衡
- 高可用性

**部署命令：**

```bash
docker swarm init
docker stack deploy -c docker-compose.yml btc-engine
```

---

### 场景4: 云平台部署

**推荐方案**: Docker + 云服务

**理由：**

- 云原生支持
- 自动扩缩容
- 托管服务

**支持平台：**

- AWS ECS / EKS
- Google Cloud Run / GKE
- Azure Container Instances / AKS
