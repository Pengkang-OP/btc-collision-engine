## [TARGET] 技术细节

### 宽度计算原理

**ttk.Combobox的width参数**:

- 单位: 字符数（基于当前字体）
- 字体: Microsoft YaHei, 9pt
- 中文字符宽度 ≈ 英文字符宽度

**计算公式**:

```
所需宽度 = 最长选项字符数 + 边距 + 下拉箭头
         = 4 + 6 + 2
         = 12字符
```

**为什么选择12**:

- [OK_CHECK] 足够显示"性能优先"（4字符）
- [OK_CHECK] 留有合适边距（6字符）
- [OK_CHECK] 包含下拉箭头空间（2字符）
- [OK_CHECK] 视觉平衡，不拥挤不宽松
