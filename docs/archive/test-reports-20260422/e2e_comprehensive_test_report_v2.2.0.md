## 9. 已知问题

### 9.1 Python 3.14 + pytest兼容性

**问题**: pytest 9.0.2在Python 3.14.3上有I/O崩溃问题  
**影响**: 无法使用pytest运行完整测试套件  
**临时方案**: 使用直接执行测试脚本  
**优先级**: 低 (不影响代码质量)

### 9.2 GPU缓冲区释放警告

**问题**: `_keys_buf`和`_match_buf`释放时出现double-unref警告  
**影响**: 低风险 - 缓冲区在GPU上下文清理时会自动释放  
**建议**: 后续优化缓冲区释放逻辑  
**优先级**: 低
