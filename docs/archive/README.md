## [SEARCH] 如何使用

### 查找文档

1. **按类型查找**: 根据文档类型进入对应目录
2. **按时间查找**: 查看temp-reports-20260422等时间标记目录
3. **按功能查找**: 如GPU相关查看gpu-related/, UI相关查看ui-related/

### 文档维护

- **新增历史报告**: 直接归档到对应分类目录
- **不要删除**: 所有归档文档都应保留
- **保持分类**: 确保文档放入正确的分类目录

## [MEMO] 注意事项

1. 归档文档为历史记录,不建议修改
2. 如需引用归档文档,请使用相对路径
3. 新增文档应先评估是否需要归档
4. 定期清理重复或过时文档(但仍保留在archive中)
