## 🎯 异常处理最佳实践总结

### 1. 异常分类层次

```python
try:
    # 业务逻辑
    pass
except (ValueError, TypeError, OverflowError) as e:
    # 第一层：参数错误（可预期，记录类型）
    logger.error("参数错误: %s", type(e).__name__)
except (IOError, OSError) as e:
    # 第二层：系统错误（可预期，记录详情）
    logger.error("系统错误: %s", e)
except Exception as e:
    # 第三层：未知错误（记录完整堆栈）
    logger.exception("未知错误")
```

### 2. 日志级别选择

| 异常类型 | 日志级别 | 说明 |
|---------|---------|------|
| 预期异常 | DEBUG | 正常的业务逻辑分支 |
| 可恢复错误 | WARNING | 可降级处理，不影响主流程 |
| 严重错误 | ERROR | 影响功能但程序可继续运行 |
| 未知错误 | ERROR + exception() | 需要立即调查的问题 |

### 3. 异常链使用

```python
# ✅ 推荐：保留原始异常
try:
    process_data()
except ValueError as e:
    raise CustomError("处理失败") from e

# ❌ 不推荐：丢失原始异常
try:
    process_data()
except ValueError as e:
    raise CustomError("处理失败")
```

### 4. 资源清理

```python
# ✅ 推荐：使用 finally 确保清理
try:
    resource.acquire()
    use_resource()
except Exception as e:
    logger.error("错误: %s", e)
finally:
    resource.release()  # 无论如何都会执行
```
