## 🟡 中危问题 (5个)

### M1: 裸异常捕获过多 (25处)

**严重程度**: 中  
**影响范围**: 异常处理、日志记录  
**文件分布**: 12个文件

**问题描述**:
代码中存在25处 `except Exception:` 或 `except:` 裸异常捕获，可能掩盖重要错误。

**示例**:

```python
# src/gui/components/alert_panel.py:212
except:  # ❌ 裸异常捕获
    return timestamp[:19]

# src/monitoring/data_logger.py:106
except Exception:  # ❌ 过于宽泛
    pass
```

**风险**:

- 掩盖关键错误（如 KeyboardInterrupt, SystemExit）
- 难以调试和追踪问题根因
- 违反异常处理最佳实践

**修复建议**:

```python
# 修复后
except (ValueError, TypeError) as e:  # ✅ 具体异常
    logger.warning(f"时间戳解析失败: {e}")
    return timestamp[:19]
```

**优先级**: P1 (高)

---

### M2: 私钥数据可能泄露到日志

**严重程度**: 中  
**影响范围**: 数据安全  
**文件**: `src/gpu/data_monitor.py`

**问题描述**:
私钥数据在质量检查时被记录到日志和details字典中。

**问题代码**:

```python
# src/gpu/data_monitor.py:439
message=f"无效的私钥格式: 长度={len(private_key)}",
details={'private_key_length': len(private_key)}

# src/gpu/data_monitor.py:462
message=f"检测到重复的私钥: {private_key[:16]}...",
details={'private_key_prefix': private_key[:16]}
```

**风险**:

- 私钥前缀(16字符)可能被记录到日志文件
- 日志文件可能被未授权访问
- 违反私钥安全管理原则

**修复建议**:

```python
# 修复后：使用哈希代替明文
import hashlib
key_hash = hashlib.sha256(private_key[:16].encode()).hexdigest()[:8]
message=f"检测到重复的私钥: hash={key_hash}...",
details={'private_key_hash': key_hash}
```

**优先级**: P1 (高)
