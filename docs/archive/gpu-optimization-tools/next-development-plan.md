### 任务1: ULLS优化效果验证 (P0 - 本周)

**优先级**: [RED] P0 (最高)  
**预计时间**: 1-2天  
**负责人**: 用户 + AI协助

#### 背景

用户已完成Intel Arc ULLS(Ultra Low Latency Submission)的手动禁用操作。根据Intel官方文档,禁用ULLS后预期Compute性能提升**14-31%**。

#### 具体步骤

1. **确认ULLS已禁用** [OK_CHECK]
   - 打开Intel Arc Control
   - 确认"超低延迟提交"选项已关闭
   - 截图记录配置

2. **运行性能基准测试** [HOURGLASS]

   ```bash
   # 快速测试
   python tools/verify_ulls_optimization.py --duration 60
   
   # 详细测试
   python run_async_test.py
   python tools/monitor_async_continuous.py 300
   ```

3. **收集性能数据** [HOURGLASS]
   - 峰值吞吐量 (keys/s)
   - 平均吞吐量 (keys/s)
   - GPU利用率 (%)
   - 运算连续性 (间隔时间)

4. **对比分析** [HOURGLASS]

   | 指标 | 优化前 | 预期后 | 实际 | 提升 |
   |------|--------|--------|------|------|
   | 峰值吞吐量 | 2.73M | 3.11-3.57M | 待测 | +14-31% |
   | 平均吞吐量 | ~47K | ~60-75K | 待测 | +27-59% |
   | GPU利用率 | 40-95% | 70-85% | 待测 | +20% |
   | 运算间隔 | 有间隔 | 减少50%+ | 待测 | 显著改善 |

5. **生成验证报告** [HOURGLASS]
   - 性能对比图表
   - 数据分析
   - 结论和建议

**概率**: 低  
**影响**: 高  
**应对**:

- 分析崩溃日志

**影响**: 中
