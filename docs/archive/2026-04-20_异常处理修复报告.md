```python
def cleanup(self):
    """释放资源"""
    if self.queue:
        try:
            self.queue.finish()
        except Exception as e:  # ✅ 仅捕获 Exception
            # 清理时记录调试日志，但不影响后续清理
            logger.debug(f"GPU队列清理失败: {type(e).__name__}")
        finally:
            self.queue = None  # ✅ 使用finally确保清理
    
    if self.context:
        try:
            del self.context
        except Exception as e:
            logger.debug(f"GPU上下文清理失败: {type(e).__name__}")
        finally:
            self.context = None
    
    self.device = None
```

#### 修复说明
- **资源保证释放**: 使用 `finally` 确保即使异常也清理引用
- **调试支持**: 记录清理失败的调试日志
- **分开清理**: 分别处理 queue 和 context，避免一个失败影响另一个

```python
@staticmethod
def is_gpu_available() -> bool:
    """检查 GPU 是否可用"""
    if not PYOPENCL_AVAILABLE:
        return False
    try:
        devices = GPUDevice.detect_devices()
        return len(devices) > 0
    except (ImportError, RuntimeError, OSError) as e:  # ✅ 捕获预期的设备检测异常
        # 预期的设备检测异常
        logger.debug(f"GPU检测失败: {type(e).__name__}: {e}")
        return False
    except Exception as e:  # ✅ 兜底捕获，记录日志
        # 未知错误：记录日志
        logger.warning(f"GPU检测未知错误: {type(e).__name__}: {e}")
        return False
```

#### 修复说明
- **异常分类**: 区分预期的设备检测异常和未知错误
- **日志级别**: 预期异常用 DEBUG，未知错误用 WARNING
- **调试支持**: 记录异常类型和消息，便于排查问题
