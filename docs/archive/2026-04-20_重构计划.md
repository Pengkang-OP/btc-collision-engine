## 重构-01: 主引擎文件拆分

### 问题描述
- **文件**: `src/collision/key_collision_engine.py` (1057行)
- **问题**: 单文件职责过多,包含引擎核心、工作线程、数据日志、统计更新等
- **影响**: 维护困难,代码可读性下降

### 重构方案

#### 目标结构
```
src/collision/
├── key_collision_engine.py      # 主引擎协调器 (~300行)
│   └── KeyCollisionEngine       # 仅保留协调和调度逻辑
├── workers/                      # 工作线程模块 (新建)
│   ├── __init__.py
│   ├── base_worker.py           # 工作线程基类 (~100行)
│   ├── random_worker.py         # 随机碰撞工作线程 (~200行)
│   ├── range_worker.py          # 范围扫描工作线程 (~150行)
│   └── brute_force_worker.py    # 暴力穷举工作线程 (~150行)
├── data_logging_handler.py      # 数据日志处理 (~200行,新建)
│   └── DataLoggingHandler       # 从引擎提取日志逻辑
└── stats_updater.py             # 统计更新逻辑 (~150行,新建)
    └── StatsUpdater             # 从引擎提取统计逻辑
```
