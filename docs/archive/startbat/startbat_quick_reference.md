## 🔧 常见问题

### Q1: 我想直接启动，不想看菜单

**A**: 使用命令别名：

```bash
start.bat qr        # 快速模式
start.bat --quick-run
```

### Q2: targets.txt放在哪里？

**A**: 和start.bat同一目录：

```
btc-collision-engine/
├── start.bat
├── targets.txt      ← 放在这里
└── key_collision_cli.py
```

### Q3: 可以修改默认选项吗？

**A**: 当前默认是选项1，如需修改：
编辑start.bat，找到：

```batch
if "!START_MODE!"=="" set "START_MODE=1"
```

改为2或3。

### Q4: 如何取消启动？

**A**: 三种方式：

1. 菜单中选择 0
2. 按 Ctrl+C
3. 关闭命令行窗口
