## ⚠️ 发现的问题与改进建议

### 🔴 高优先级问题 (P0 - 必须修复)

#### P0-1: 裸 except 子句 (5处)

**位置**:
- `src/core/secure_key_manager.py:261`
- `src/collision/checkpoint_manager.py:151`
- `src/collision/gpu_collision_engine.py:211, 563`
- `src/collision/targets/storage.py:216`

**问题**:
```python
# ❌ 危险：捕获所有异常包括 KeyboardInterrupt, SystemExit
except:
    pass
```

**风险**:
- 可能捕获 `KeyboardInterrupt` 导致无法 Ctrl+C 退出
- 可能捕获 `SystemExit` 阻止正常退出
- 隐藏严重错误（如 MemoryError）

**修复建议**:
```python
# ✅ 修复：指定具体异常类型
except Exception:
    # 或者更具体的异常
except (OSError, ValueError, TypeError):
    pass
```

**影响范围**: 5个文件，5处代码  
**修复难度**: ⭐ (5分钟/处)  
**修复优先级**: 🔴 立即修复

#### P1-3: SecureKeyManager 的 __del__ 方法使用裸 except

**位置**: `src/core/secure_key_manager.py:255-262`

**问题**:
```python
def __del__(self):
    """析构函数 - 确保清零"""
    if self._key is not None and not self._cleared:
        try:
            self.clear()
        except:  # ❌ 裸 except
            pass
```

**风险**:
- `__del__` 中的异常会被静默忽略，但裸 except 会捕获 `KeyboardInterrupt`
- 在 Python 3.4+ 中，`__del__` 的异常会打印到 stderr

**修复建议**:
```python
def __del__(self):
    """析构函数 - 确保清零"""
    if self._key is not None and not self._cleared:
        try:
            self.clear()
        except Exception:
            # 析构函数中忽略异常，但记录调试信息
            pass
```

**影响范围**: 1个文件  
**修复难度**: ⭐ (5分钟)  
**修复优先级**: 🟡 本周修复

**位置**: `src/core/crypto_backend.py:512-517`

**问题**:
```python
if logger.isEnabledFor(logging.DEBUG):
    start_time = time.perf_counter()
    result = backend.generate_public_key(private_key, compressed)
    elapsed_ms = (time.perf_counter() - start_time) * 1000
    logger.debug(f"公钥生成: {backend.name}, 耗时={elapsed_ms:.3f}ms")
```

```python
backend = self.current_backend

if logger.isEnabledFor(logging.DEBUG):
    start_time = time.perf_counter()
    result = backend.generate_public_key(private_key, compressed)
    elapsed_ms = (time.perf_counter() - start_time) * 1000
    logger.debug(f"公钥生成: {backend.name}, 耗时={elapsed_ms:.3f}ms")
    return result

return backend.generate_public_key(private_key, compressed)
```

**当前实现已可接受**，优化后更简洁

**位置**: 多处模块内部导入

```python
# src/core/crypto_backend.py:109
def __init__(self, use_const_time: bool = False):
```

**建议**:

- 如果是疏忽，移到文件顶部
