### 1. SecureKeyManager.__del__ ✅

**文件**: `src/core/secure_key_manager.py`  
**修改**: `except:` → `except Exception:`

#### 审查分析

**行为变更**:
- 修复前：捕获所有异常（包括 KeyboardInterrupt、SystemExit）
- 修复后：仅捕获 Exception 及其子类

**回归风险评估**:
1. ✅ **不会丢失异常**: 
   - `clear()` 方法内部抛出的异常都是 Exception 子类
   - 不会抛出 KeyboardInterrupt 或 SystemExit
   - 不会影响程序正常退出

2. ✅ **私钥安全不受影响**:
   - 析构函数中异常被静默忽略（设计意图）
   - 即使异常未被捕获，对象仍在销毁，私钥会被 GC 回收
   - 不影响 secure_clear 的执行

3. ✅ **控制流不变**:
   - `pass` 仍然执行，行为完全一致
   - 不影响其他代码执行

**场景模拟**:
```python
# 场景1：正常清零
self.clear()  # 成功
except Exception:  # 不执行
pass  # 不执行
✅ 无影响

# 场景2：清零失败（ValueError）
self.clear()  # 抛出 ValueError
except Exception:  # 捕获
pass  # 静默忽略
✅ 与修复前行为一致

# 场景3：KeyboardInterrupt（理论上不会发生）
self.clear()  # 抛出 KeyboardInterrupt
except Exception:  # 不捕获
# 异常向上传播
✅ 更好的行为（允许程序退出）
```

**结论**: ✅ **无回归风险，行为改进**

### 3. GPUDevice.cleanup() ✅

**文件**: `src/collision/gpu_collision_engine.py`  
**修改**: 裸except + 直接赋值 → except Exception + finally 确保清理

#### 审查分析

**行为变更**:
- 修复前：异常时可能不清理 queue 引用
- 修复后：使用 finally 确保清理

**回归风险评估**:
1. ✅ **资源管理改进**:
   ```python
   # 修复前
   except:
       pass
   self.queue = None  # 如果前面 return 或 raise，这行不执行
   
   # 修复后
   except Exception:
       logger.debug(...)
   finally:
       self.queue = None  # 保证执行
   ```
   - 这是**改进**，不是回归

2. ✅ **分离 context 清理**:
   ```python
   # 修复前：queue 异常会影响 context 清理
   self.queue = None
   self.context = None  # 如果上面异常，可能不执行
   
   # 修复后：独立清理
   if self.context:
       try:
           del self.context
       except Exception:
           logger.debug(...)
       finally:
           self.context = None
   ```
   - 提高了健壮性

3. ✅ **日志改进**:
   - 清理失败记录 DEBUG 日志
   - 不影响主流程

**场景模拟**:
```python
# 场景1：queue.finish() 成功
self.queue.finish()  # 成功
finally:
    self.queue = None  # 清理
self.context = None
✅ 行为一致

# 场景2：queue.finish() 失败（RuntimeError）
self.queue.finish()  # 抛出 RuntimeError
except Exception:  # 捕获
logger.debug(...)  # 记录日志
finally:
    self.queue = None  # 保证清理 ✅ 改进
# 继续清理 context
✅ 更好的行为

# 场景3：context 删除失败
del self.context  # 抛出异常
except Exception:  # 捕获
logger.debug(...)
finally:
    self.context = None  # 保证清理 ✅ 改进
✅ 更好的行为
```

**结论**: ✅ **无回归风险，显著改进资源管理**

### P2-1: 工作线程池异常处理可进一步细化

**位置**: `key_collision_engine.py:482, 681`  
**当前代码**:
```python

    logger.error(f"工作线程 {worker_id} 出错: {e}")
```

**建议**:
```python

    # 线程执行错误

    logger.info(f"工作线程 {worker_id} 被取消")
except Exception as e:
    # 未知错误
    logger.exception(f"工作线程 {worker_id} 未知错误")
```

**风险等级**: 🟢 低
