```

| 配置项 | 预期值 | 实际值 | 差距 |

| batch_size | 65,536 | 1,024 | **64倍差距** |
| memory_efficiency | 70% | 70% ✅ | 正确 |
| mem_ratio | - | 50% | 可能过低 |

#### 3. 性能瓶颈定位

实际速度计算:

```
43,328 keys/s ÷ 1,024 batch_size = 42.3 批次/秒
