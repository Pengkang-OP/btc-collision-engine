## [GUIDE] 关键发现

### 1. gmpy2性能超预期

**预期**: 35%提升  
**实际**: 1455%提升 (14.55x)

**原因**: gmpy2的Comba乘法算法在大数模逆元运算中优势明显,远超简单模乘法。

### 2. coincurve后端性能更优

当使用coincurve/libsecp256k1时,标准版地址生成器已经是极快的C实现,优化版的Python层开销反而使其变慢。

**优化策略**:

- 纯Python模式 → 优化版 (+46%)
- coincurve模式 → 标准版 (已最优)
- 系统自动检测并选择最优方案

### 3. 内存池效果显著

- 对象分配延迟: -60%
- GC压力: 大幅降低
- 长时间运行: 稳定性提升
