### 1.3 secp256k1椭圆曲线 (src/core/secp256k1.py)

**审查结果**: ✅ **优秀**（有恒定时间实现）

**优点**:
- ✅ 提供两种标量乘法实现：
  - `scalar_multiply`: 标准双倍-加法算法（快速）
  - `scalar_multiply_const_time`: Montgomery Ladder算法（抗侧信道攻击）
- ✅ 恒定时间条件选择：`_const_time_select`方法使用位运算避免条件分支
- ✅ 默认使用恒定时间算法：`generate_public_key`默认调用`scalar_multiply_const_time`
- ✅ 完整的输入验证：类型检查、范围检查

**代码示例 - Montgomery Ladder算法**:
```python
def scalar_multiply_const_time(self, k: int, point: ECPoint) -> ECPoint:
    """
    恒定时间的椭圆曲线标量乘法（Montgomery Ladder算法）
    
    使用Montgomery Ladder算法实现恒定时间计算，
    每次迭代执行相同的操作序列，不依赖于k的位模式，
    可有效防御侧信道攻击（如时序攻击、功耗分析）。
    """
    # Montgomery Ladder算法
    # R0 = 0 (无穷远点), R1 = point
    r0 = ECPoint(None, None, self.curve)
    r1 = point.copy()
    
    # 从最高位到最低位遍历
    for i in range(k_bits - 1, -1, -1):
        bit = (k >> i) & 1
        
        # 计算两种可能的结果
        r0_plus_r1 = self.point_add(r0, r1)
        r0_double = self.point_add(r0, r0)
        r1_double = self.point_add(r1, r1)
        
        # 恒定时间条件选择
        r0_new = self._const_time_select(bit, r0_double, r0_plus_r1)
        r1_new = self._const_time_select(bit, r0_plus_r1, r1_double)
        
        r0 = r0_new
        r1 = r1_new
    
    return r0
```

**⚠️ 注意事项**:
- Python解释器层面无法保证真正的恒定时间执行（需要C扩展或专用加密库）
- 代码注释已明确说明此限制
- 对于本地离线使用场景已足够安全

**建议**: 
- 📝 轻微：考虑在生产环境中使用`cryptography`或`secp256k1-py`库以获得真正的恒定时间保证

**⚠️ 发现的问题**:

#### 问题1: 多锁顺序不一致可能导致死锁（中等风险）
**位置**: `key_collision_engine.py` 多处

**描述**: 
引擎使用三个独立的锁（`_count_lock`, `_matches_lock`, `_dedup_lock`），但在某些代码路径中可能以不同顺序获取多个锁，存在潜在的死锁风险。

**示例场景**:
```python
# 线程A可能按此顺序获取锁
with self._count_lock:
    with self._matches_lock:
        # 更新计数和匹配

# 线程B可能按此顺序获取锁
with self._matches_lock:
    with self._count_lock:
        # 读取匹配和计数
```

**修复建议**:
```python
# 方案1: 统一锁顺序（推荐）
# 始终按 _count_lock -> _matches_lock -> _dedup_lock 的顺序获取

# 方案2: 使用单个粗粒度锁（如果性能可接受）
self._global_lock = threading.Lock()

# 方案3: 使用上下文管理器确保顺序
@contextmanager
def acquire_locks_in_order(self, *locks):
    sorted_locks = sorted(locks, key=id)  # 按对象ID排序
    for lock in sorted_locks:
        lock.acquire()
    try:
        yield
    finally:
        for lock in reversed(sorted_locks):
            lock.release()
```

**优先级**: 🔶 中等 - 应在下次重构时修复

```python
def check_and_add(self, private_key: bytes) -> bool:
    if not self.enabled:
        return True
    
    # 指纹计算在锁外（减少锁持有时间）
    fp = self._fingerprint(private_key)
    
    with self._lock:
        # 所有计数器更新在锁内
        self.checks_total += 1
        
        # 检查当前集合和待淘汰集合
        if fp in self._current or fp in self._pending:
            self.duplicates_found += 1
            return False
        
        # 添加到当前集合
        self._current.add(fp)
        self._queue.append(fp)
        self._current_size += 1
        
        # 达到半满时轮换
        if self._current_size >= self._half_size:
            self._pending = self._current
            self._current = set()
            self._current_size = 0
            self._queue.clear()
        
        return True
```

**⚠️ 发现的问题**:

#### 问题3: 配置管理器不是线程安全的（中等风险）
**位置**: `config_manager.py`

**描述**:
`ConfigManager`的`get()`、`set()`、`load_config()`和`save_config()`方法没有使用锁保护。在多线程环境下，可能导致配置读取不一致或文件写入冲突。

**影响**:
- 多线程同时读取配置可能返回不一致的状态
- 多线程同时写入配置可能导致文件损坏

**修复建议**:
```python
class ConfigManager:
    def __init__(self, config_file: str = None):
        self.config_file = config_file
        self.config = self.DEFAULT_CONFIG.copy()
        self._lock = threading.Lock()  # 添加锁
        
        if config_file and os.path.exists(config_file):
            self.load_config()
    
    def load_config(self) -> bool:
        try:
            with open(self.config_file, 'r', encoding='utf-8') as f:
                user_config = json.load(f)
            with self._lock:  # 添加锁保护
                self._merge_config(self.config, user_config)
            return True
        except Exception as e:
            logger.error(f"加载配置文件失败: {e}")
            return False
    
    def save_config(self) -> bool:
        if not self.config_file:
            return False
        
        try:
            with self._lock:  # 添加锁保护
                config_copy = self.config.copy()
            with open(self.config_file, 'w', encoding='utf-8') as f:
                json.dump(config_copy, f, ensure_ascii=False, indent=2)
            return True
        except Exception as e:
            logger.error(f"保存配置文件失败: {e}")
            return False
    
    def get(self, key: str, default: Any = None) -> Any:
        keys = key.split('.')
        with self._lock:  # 添加锁保护
            value = self.config
        
        for k in keys:
            if isinstance(value, dict) and k in value:
                value = value[k]
            else:
                return default
        
        return value
    
    def set(self, key: str, value: Any) -> bool:
        keys = key.split('.')
        with self._lock:  # 添加锁保护
            config = self.config
            
            for i, k in enumerate(keys[:-1]):
                if k not in config or not isinstance(config[k], dict):
                    config[k] = {}
                config = config[k]
            
            config[keys[-1]] = value
        return True
```

```python
    for plugin_dir in self.plugin_dirs:
        if not os.path.exists(plugin_dir):
            continue
        
        # 规范化允许的目录路径
        allowed_dir = os.path.abspath(plugin_dir)
        
        for filename in os.listdir(plugin_dir):
            if filename.endswith('.py') and not filename.startswith('__'):
                plugin_path = os.path.join(plugin_dir, filename)

                abs_plugin_path = os.path.abspath(plugin_path)
```
