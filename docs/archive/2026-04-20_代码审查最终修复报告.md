## 二、详细修复内容

### 2.1 修复temp_file未定义问题 (Low)

**审查问题**: 如果`tempfile.mkstemp()`抛出异常，`temp_file`变量未定义，会导致`NameError`

**修复方案**: 在try块之前初始化`temp_file = None`

#### 修复位置1: save_current_data()

**文件**: `data_logger.py` 第303行

**修复前**:
```python
def save_current_data(self):
    # 在锁外执行I/O操作
    try:
        temp_fd, temp_file = tempfile.mkstemp(...)  # ⚠️ 可能失败
        # ...
    except Exception as e:
        self.logger.error(f"保存当前数据失败: {e}")
        try:
            if os.path.exists(temp_file):  # ⚠️ NameError风险
                os.remove(temp_file)
```

**修复后**:
```python
def save_current_data(self):
    # 在锁外执行I/O操作
    temp_file = None  # ✅ 初始化，避免NameError
    try:
        temp_fd, temp_file = tempfile.mkstemp(...)
        # ...
    except Exception as e:
        self.logger.error(f"保存当前数据失败: {e}")
        try:
            if temp_file and os.path.exists(temp_file):  # ✅ 安全检查
                os.remove(temp_file)
```

#### 修复位置2: save_history_data()

**文件**: `data_logger.py` 第342行

**修复内容**: 同样的修复模式

**修复前**:

**修复后**:
```python
temp_file = None  # ✅ 初始化

```

**效果**:
- ✅ 消除NameError风险
- ✅ 异常处理更健壮
- ✅ 代码更清晰

### 2.2 添加JSON恢复文件大小限制 (Low)

**审查问题**: 没有检查文件大小，理论上可能读取超大文件耗尽内存

**修复方案**: 在读取文件前检查大小，限制为10MB

**文件**: `data_logger.py` 第417-425行

**修复前**:
```python
def _recover_history_data(self) -> list:
    recovered = []
    
    try:
        with open(self.history_data_file, 'r', encoding='utf-8') as f:
            content = f.read()  # ⚠️ 无大小限制
```

**修复后**:
```python
def _recover_history_data(self) -> list:
    """尝试从损坏的JSON文件中恢复数据（健壮的逐行解析）"""
    recovered = []
    
    try:
        # 防御性编程：检查文件大小，避免读取超大文件耗尽内存
        file_size = os.path.getsize(self.history_data_file)
        max_size = 10 * 1024 * 1024  # 10MB限制
        if file_size > max_size:
            self.logger.error(
                f"历史文件过大({file_size / 1024 / 1024:.2f}MB)，"
                f"超过限制({max_size / 1024 / 1024:.0f}MB)，跳过恢复"
            )
            return []
        
        with open(self.history_data_file, 'r', encoding='utf-8') as f:
            content = f.read()
```

**效果**:
- ✅ 防止内存耗尽攻击
- ✅ 防御性编程最佳实践
- ✅ 清晰的错误日志
- ✅ 合理的限制（10MB远大于正常的500KB）

**限制选择理由**:
- 正常文件: ~500KB (1000条记录)
- 10MB限制: 是正常大小的20倍
- 足够容纳异常情况
- 防止恶意或错误的大文件
