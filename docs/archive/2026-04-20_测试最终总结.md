    mock_class.return_value = instance

## 附录C：引擎竞态条件修复（2026-04-19）

### C.1 问题分析

**问题**: 引擎stop()后，工作线程的统计信息未及时更新到stats对象，导致测试立即检查时得到0值。

**旧方案（治标不治本）**:
```python
# stop()方法中使用固定等待时间
time.sleep(0.5)  # 不可靠，可能太快或太慢
```

### C.2 解决方案：事件通知机制

**实现**:
```python
# 添加统计更新完成事件
self._stats_updated = threading.Event()
self._stats_updated.set()  # 初始状态为已更新

# 在统计更新后设置事件
self._stats_updated.clear()  # 清除事件
self.stats.update(final_count)
self._stats_updated.set()  # 设置事件，通知更新完成

# 测试中等待事件
engine._stats_updated.wait(timeout=2.0)  # 等待统计更新完成
```

### C.3 修复效果

- ✅ **根本修复**：使用事件通知替代固定等待
- ✅ **恢复6个测试**：所有性能/稳定性测试100%通过
- ✅ **添加自动化性能回归检测**：pytest-benchmark框架
