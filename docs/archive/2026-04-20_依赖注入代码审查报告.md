## 🟠 High问题（高级）

### 1. analyze_trends()方法缺少空值保护

**位置**: 第453-495行  
**问题**: `analyze_trends()`方法直接使用`d["performance"]`，如果数据格式不正确会抛出KeyError

**当前代码**:
```python
def analyze_trends(self, history_data: List[Dict[str, Any]]) -> Dict[str, Any]:
    """分析趋势"""
    if len(history_data) < 10:
        return {"message": "历史数据不足，无法分析趋势"}
    
    recent_data = history_data[-100:]
    
    # ❌ 如果d中没有"performance"键会抛出KeyError
    speeds = [d["performance"].get("speed", 0) for d in recent_data]
    cpu_usages = [d["performance"].get("cpu_usage", 0) for d in recent_data]
    memory_usages = [d["performance"].get("memory_usage", 0) for d in recent_data]
```

**风险**: 
- 如果历史数据格式不一致（某些记录缺少"performance"键），会导致崩溃
- `_simple_trend_analysis()`方法已经使用了安全访问`d.get("performance", {})`，但`analyze_trends()`没有

**建议修复**:
```python
def analyze_trends(self, history_data: List[Dict[str, Any]]) -> Dict[str, Any]:
    """分析趋势"""
    if len(history_data) < 10:
        return {"message": "历史数据不足，无法分析趋势"}
    
    recent_data = history_data[-100:]
    
    # ✅ 使用安全访问
    speeds = [d.get("performance", {}).get("speed", 0) for d in recent_data]
    cpu_usages = [d.get("performance", {}).get("cpu_usage", 0) for d in recent_data]
    memory_usages = [d.get("performance", {}).get("memory_usage", 0) for d in recent_data]
```

**影响**: 中等 - 在生产环境中可能导致报告生成失败

### 2. detect_anomalies()中循环内调用save_error()性能问题

**位置**: 第441-453行  
**问题**: 在循环中逐个保存异常记录，可能导致多次I/O操作

**当前代码**:
```python
if self.storage is not None and anomalies:
    try:
        for anomaly in anomalies:  # ❌ 每个异常都调用一次save_error
            self.storage.save_error({
                "type": "anomaly_detection",
                "level": "warning",
                "message": anomaly["message"],
                "details": anomaly
            })
    except Exception as e:
        logger.error(f"保存异常记录失败: {e}")
```

**问题**:
- 如果检测到3个异常，会调用3次`save_error()`
- 每次调用都会读取-修改-写入文件（原子写入）
- 性能开销较大

**建议优化**:
```python
if self.storage is not None and anomalies:
    try:
        # ✅ 批量保存或只保存最严重的异常
        for anomaly in anomalies:
            self.storage.save_error({
                "type": "anomaly_detection",
                "level": "warning",
                "message": anomaly["message"],
                "details": anomaly
            })
    except Exception as e:
        logger.error(f"保存异常记录失败: {e}")
```

**或者更好的方案** - 添加批量保存方法到DataStorage:
```python
if self.storage is not None and anomalies:
    try:
        # 批量保存（如果DataStorage支持）
        errors = [{
            "type": "anomaly_detection",
            "level": "warning",
            "message": a["message"],
            "details": a
        } for a in anomalies]
        self.storage.save_errors_batch(errors)  # 批量保存
    except Exception as e:
        logger.error(f"保存异常记录失败: {e}")
```

**影响**: 低 - 当前实现功能正确，但性能可优化

```python
# 方案1: 提取为静态方法
@staticmethod
def _calculate_trend(values: List[float]) -> str:
    """计算趋势"""
    if len(values) < 2:
        return "stable"
    first_half_avg = statistics.mean(values[:len(values)//2])
    second_half_avg = statistics.mean(values[len(values)//2:])
    
    if second_half_avg > first_half_avg * 1.05:
        return "increasing"
    elif second_half_avg < first_half_avg * 0.95:
        return "decreasing"
    else:
        return "stable"

def _simple_trend_analysis(self, data: List[Dict[str, Any]]) -> Dict[str, Any]:
    # ...
    return {
        "speed": {"trend": self._calculate_trend(speeds)},
        "cpu_usage": {"trend": self._calculate_trend(cpu_usages)},
        "memory_usage": {"trend": self._calculate_trend(memory_usages)}
    }
```

### 6. generate_alert()中print语句不适合生产环境

**位置**: 第540-542行  
**问题**: 使用print输出告警信息，不适合生产环境

**当前代码**:
```python
def generate_alert(self, anomaly: Dict[str, Any]):
    # ...
    
    # 打印告警
    level_color = "\033[91m" if alert["level"] == "critical" else "\033[93m"
    reset_color = "\033[0m"
    print(f"{level_color}[ALERT] {datetime.fromtimestamp(alert['timestamp']).strftime('%Y-%m-%d %H:%M:%S')} - {alert['message']}{reset_color}")
    
    # 记录到日志
    logger.warning(f"ALERT: {alert['message']} - Details: {json.dumps(anomaly)}")
```

**问题**:
- print语句直接输出到stdout，无法控制
- 生产环境应该只使用logger
- ANSI颜色代码在非终端环境可能显示异常

**建议优化**:
```python
def generate_alert(self, anomaly: Dict[str, Any]):
    # ...
    
    # 记录到日志（使用合适的日志级别）
    if alert["level"] == "critical":
        logger.critical(f"ALERT: {alert['message']} - Details: {json.dumps(anomaly)}")
    else:
        logger.warning(f"ALERT: {alert['message']} - Details: {json.dumps(anomaly)}")
    
    # 可选：保留print用于调试模式
    # if DEBUG_MODE:
    #     print(f"[ALERT] {alert['message']}")
```
