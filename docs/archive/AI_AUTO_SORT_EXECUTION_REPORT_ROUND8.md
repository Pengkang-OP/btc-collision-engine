- 存在明显的收益递减

**教训**:

- 需要找到最优批次大小
- 考虑其他瓶颈因素
- 实际测试验证很重要

**发现**:

- 单一优化效果有限

**教训**:

- 制定系统性优化计划

- 持续测试和验证
