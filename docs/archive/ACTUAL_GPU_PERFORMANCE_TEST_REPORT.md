## [SEARCH] 问题分析

### 预期vs实际的差异

#### 为什么低于预期？

**预期**: 130,000-170,000 keys/s  
**实际**: 43,323 keys/s  
**差距**: 约3-4倍

**可能原因**:

1. **显存效率配置问题**
   - 日志显示: `[OK_CHECK] Intel GPU内存效率: 45% (保守策略)`
   - v2.2.1优化目标: 70%
   - **实际问题**: 代码中应用的是45%的保守策略，而非70%

2. **批次大小降级**
   - 配置批次: 65,536
   - 日志警告: `显存不足,批次大小从 16,384 调整为最小值 1,024`
   - **问题**: 显存计算逻辑可能导致批次大小被错误调整

3. **同步模式限制**
   - 日志: `使用GPU同步执行模式`
   - 日志: `Intel GPU: 禁用异步传输以确保稳定性`
   - **影响**: 同步模式无法充分利用GPU并行性

4. **uint32 workaround开销**
   - 日志: `Intel Arc存在global char* hang bug, 已启用uint32 workaround`
   - **影响**: workaround可能引入额外计算开销
