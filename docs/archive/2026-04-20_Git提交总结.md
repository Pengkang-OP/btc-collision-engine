## 功能概述

### 核心功能

1. **地址导入** - `import_addresses()` 方法
   - 支持从TXT、JSON、CSV文件导入
   - 自动检测文件格式
   - 批量处理和验证

2. **地址验证**
   - 集成 AddressBatchValidator
   - 验证P2PKH、P2SH、Bech32地址格式
   - 过滤无效地址

3. **持久化存储**
   - 支持JSON、SQLite、CSV格式
   - 自动保存有效地址
   - 记录完整元数据

4. **进度反馈**
   - 支持进度回调函数
   - 实时导入进度

## 使用示例

```python
from src.collision.targets.storage import AddressStorage

# 创建存储实例
storage = AddressStorage()

# 导入地址
result = storage.import_addresses(
    source_path='addresses.txt',
    storage_dir='./targets_data',
    validate=True,
    storage_type='json'
)

print(f"导入成功: {result['success']}")
print(f"有效地址: {result['imported_count']}")
print(f"存储路径: {result['storage_path']}")
```
