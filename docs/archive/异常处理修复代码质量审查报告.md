# 改进方案

#### 2. 缺少重试机制

**文件**: `quality_trend.py`, `recommend_config.py`  
**问题**: 文件操作失败直接放弃，没有重试

**当前实现**:
```python
try:
    content = f.read_text(encoding='utf-8', errors='ignore')
except (OSError, PermissionError) as e:
    print(f"[WARN]  无法读取文件 {f.name}: {e}")
    continue  # 直接跳过
```

**建议**: 对于关键操作添加重试机制

```python
import time

def read_with_retry(file_path, max_retries=3, delay=0.1):
    """带重试的文件读取"""
    for attempt in range(max_retries):
        try:
            return file_path.read_text(encoding='utf-8', errors='ignore')
        except (OSError, PermissionError) as e:
            if attempt < max_retries - 1:
                time.sleep(delay)
                continue
            print(f"[WARN]  无法读取文件 {file_path.name} (重试{max_retries}次): {e}")
            return None
```

**影响**: 中 - 临时性错误（如文件锁）可重试恢复  
**优先级**: P1 - 建议改进

#### 6. 临时文件清理不够安全

**文件**: `quality_trend.py`  
**问题**: 如果程序在写入中途崩溃，临时文件可能残留

```python
temp_file = self.history_file.with_suffix('.tmp')
with open(temp_file, 'w', encoding='utf-8') as f:
    json.dump(self.history, f, indent=2, ensure_ascii=False)
temp_file.replace(self.history_file)
# 如果这里崩溃，.tmp文件残留
```

**建议**: 添加启动时清理

```python
def __init__(self, history_file: str = "quality_history.json"):
    self.history_file = Path(history_file)
    self._cleanup_temp()  # 清理残留临时文件
    self.history: List[Dict] = self.load_history()

def _cleanup_temp(self):
    """清理残留的临时文件"""
    temp_file = self.history_file.with_suffix('.tmp')
    if temp_file.exists():
        try:
            temp_file.unlink()
        except OSError:
            pass
```
