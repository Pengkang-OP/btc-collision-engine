## [CHART] 优先级算法说明

### 计算公式

```
优先级 = (影响范围 × 紧急程度) ÷ 实施成本
```

### 评分标准

**影响范围 (1-10)**:

- 9-10: 影响核心功能/团队协作
- 7-8: 影响用户体验/文档完整性
- 5-6: 影响次要功能
- 1-4: 影响边缘功能

**紧急程度 (1-10)**:

- 9-10: 阻塞性问题/立即需要
- 7-8: 重要但不紧急
- 5-6: 计划内任务
- 1-4: 可延后

**实施成本 (1-10)**:

- 1-2: 低成本（<5分钟）
- 3-4: 中等成本（5-30分钟）
- 5-7: 高成本（30分钟-2小时）
- 8-10: 非常高（>2小时）
