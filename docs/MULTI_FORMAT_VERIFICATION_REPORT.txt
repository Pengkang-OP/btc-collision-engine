一、多格式地址支持概述
================================================================================

本项目支持以下比特币地址格式的生成和验证：

1. P2PKH (Pay-to-Public-Key-Hash)
   - 前缀: '1'
   - 编码: Base58Check
   - 版本字节: 0x00
   - 说明: 最经典的比特币地址格式

2. P2SH (Pay-to-Script-Hash)
   - 前缀: '3'
   - 编码: Base58Check
   - 版本字节: 0x05
   - 说明: 支付到脚本哈希，支持多重签名等复杂功能

3. Bech32 (SegWit v0 - P2WPKH)
   - 前缀: 'bc1q'
   - 编码: Bech32
   - Witness版本: 0
   - 说明: 隔离见证地址，降低交易费用

4. Bech32m (SegWit v1 - Taproot/P2TR)
   - 前缀: 'bc1p'
   - 编码: Bech32m
   - Witness版本: 1
   - 说明: Taproot地址，增强隐私和效率

四、地址格式转换流程
================================================================================

1. P2PKH 地址生成:
   私钥 → 公钥 → SHA256(公钥) → RIPEMD160 → Base58Check(0x00 + Hash160)

2. P2SH 地址生成:
   私钥 → 公钥 → HASH160(公钥) → redeem_script → HASH160(redeem_script)
   → Base58Check(0x05 + script_hash)

3. Bech32 地址生成:
   私钥 → 公钥 → HASH160(公钥) → witness_program
   → Bech32编码(hrp="bc", witness_version=0)

4. Taproot 地址生成:
   私钥 → 公钥 → xonly公钥 → 32字节witness_program
   → Bech32m编码(hrp="bc", witness_version=1)
