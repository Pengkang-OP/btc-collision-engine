四、地址生成验证
================================================================================

[OK] P2PKH地址生成 (Pay-to-Public-Key-Hash)
  步骤:
    1. SHA256(公钥) → 32字节哈希
    2. RIPEMD160(SHA256结果) → 20字节Hash160
    3. 版本字节(0x00) + Hash160 → 21字节
    4. SHA256(SHA256(版本+Hash160)) → 取前4字节校验和
    5. 版本+Hash160+校验和 → Base58编码 → 地址

[OK] Hash160计算验证
  - 输入: 压缩公钥 (33字节)
  - 输出: 20字节哈希
  - 示例:
    SHA256(公钥) = 0f715baf5d4c2ed329785cef29e562f73488c8a2bb9dbc5700b361d54b9b0554
    RIPEMD160 = 751e76e8199196d454941c45d1b3a323f1433bd6

[OK] Base58Check编码验证
  - 版本字节: 0x00 (P2PKH主网)
  - 有效字符集: 123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz
  - 地址格式: 以'1'开头

测试结果:

  [OK] 地址格式验证通过

八、完整密钥流程验证
================================================================================

验证流程:
  1. 随机32字节 → 私钥 (范围验证)
  2. 私钥 × G → 公钥 (secp256k1)
  3. SHA256(公钥) → SHA256哈希
  4. RIPEMD160(SHA256) → Hash160
  5. Base58Check(0x00 + Hash160) → P2PKH地址
  6. 计算Hash160 → 与目标表比对
  7. O(1)查找 → 匹配结果

示例密钥链:
  私钥: 5e852cbd6a0e66aaa2217d1ce0353c12b547c97e...
  公钥: 036e32fce182c3538365ece9150770b1b781e080...
  地址: 1DxhGUN4J1MTnZmcAwKowwimPcuPmau9pL
  Hash160: 8e2a001385aee631572cf934c2770bcc81244d29

测试结果:
