🔐 Hash160 哈希值比对流程

目标地址与生成地址的哈希一致性验证

核心机制：公钥 → SHA256 → RIPEMD160 → 20字节Hash160 → O(1)字典查找
📥
目标地址加载流程
1
输入WIF私钥

从配置文件或用户输入读取WIF格式私钥

# 示例WIF私钥 wif = '5KJvsngHeMpm884wtkJNzQGaCErckhHJBGFsvd3VyK5qMZXj3hS'
2
WIF解码 → 私钥

解码WIF格式，提取32字节私钥和压缩标志

from src.core.wif import WIF private_key, compressed = WIF.decode(wif) # private_key: 32字节 # compressed: True/False
3
私钥 → 公钥（椭圆曲线）

使用secp256k1椭圆曲线进行标量乘法：Q = k × G

from src.core.address_generator import P2PKHAddressGenerator generator = P2PKHAddressGenerator() public_key = generator.private_key_to_public_key( private_key, compressed ) # 压缩公钥: 33字节 (02/03 + x坐标) # 非压缩公钥: 65字节 (04 + x坐标 + y坐标)
4
公钥 → Hash160

核心哈希算法：SHA256 + RIPEMD160

from src.core.hash_utils import HashUtils hash160 = HashUtils.hash160(public_key) # hash160: 20字节 # 等效于: RIPEMD160(SHA256(public_key))
5
存储到目标哈希表

将Hash160存入_set和_target_map

# src/core/target_address_table.py:74 self._hash160_set.add(hash160) # O(1)查找 self._target_map[hash160] = { 'wif': wif, 'address': address, 'hash160': hash160.hex(), 'type': address_type }
⚡
生成地址碰撞流程
1
生成随机私钥

使用加密安全随机数生成器

import secrets private_key = secrets.token_bytes(32) # 确保: 1 <= key < secp256k1.N
2
私钥 → 公钥（相同算法）

使用与目标地址相同的椭圆曲线算法

public_key = generator.private_key_to_public_key( private_key, compressed=True ) # 使用相同的secp256k1曲线
3
公钥 → Hash160（完全一致）

使用完全相同的HashUtils.hash160()函数

# CPU版本 hash160 = HashUtils.hash160(public_key) # GPU版本（OpenCL内核） uchar hash160_result[20]; hash160(pubkey, 33, hash160_result); // 输出: 20字节，与CPU完全一致
4
O(1)哈希表查找

在目标哈希表中快速查找匹配

# src/core/target_address_table.py:99 if hash160 in self._hash160_set: return True, self._target_map.get(hash160) # 时间复杂度: O(1) # 数据类型: bytes (20字节)
5
碰撞成功处理

记录匹配结果并触发回调

match_record = { 'found_at': datetime.utcnow().isoformat(), 'hash160': hash160.hex(), 'target': target_info, 'generated': addr_info } # 保存到文件/数据库 # 触发通知/回调
