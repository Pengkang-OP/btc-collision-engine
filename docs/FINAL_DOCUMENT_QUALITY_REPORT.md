## 🚀 CI/CD集成

### GitHub Actions工作流

**文件**: `.github/workflows/doc-quality.yml`

**触发条件**:
- Push到docs目录
- PR涉及文档变更
- 手动触发

**检查项**:
1. ✅ 文档质量评分
2. ✅ 断裂链接检测
3. ✅ 质量门控 (Quality Gate)
4. ✅ 报告上传 (Artifacts)

**质量门控**:
- 发现需改进文档 → ❌ 阻止合并
- 所有文档良好 → ✅ 允许合并

### Pre-commit Hook

**文件**: `tools/pre-commit-docs.sh`

**安装方法**:
```bash
# Linux/Mac
ln -s ../../tools/pre-commit-docs.sh .git/hooks/pre-commit

# Windows (Git Bash)
cp tools/pre-commit-docs.sh .git/hooks/pre-commit
```

**功能**:
- 自动检测文档变更
- 提交前质量检查
- 断裂链接警告
- 失败阻止提交
