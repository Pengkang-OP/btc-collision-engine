1. MultiFormatAddressGenerator (多格式地址生成器)
   位置: src/core/multi_format_generator.py

   功能:
     - 从单个私钥生成所有格式地址
     - 支持指定格式生成
     - 格式自动检测
     - 格式验证

   支持格式:
     - P2PKH (1xxx)
     - P2SH (3xxx)
     - Bech32 (bc1qxxx)
     - Taproot (bc1pxxx)

   示例:
     ```python
     from src.core.multi_format_generator import MultiFormatAddressGenerator

     gen = MultiFormatAddressGenerator()

     # 生成所有格式
     addresses = gen.generate_all_formats(private_key)
     print(addresses)
     # 输出:
     # {
     #     'p2pkh': '1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa',
     #     'p2sh': '3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy',
     #     'bech32': 'bc1qw508d6qejxtdg4y5r3zarvary0c5xw7kv8f3t4',
     #     'taproot': 'bc1p5d7rjq7g6rdk2yhzks9smlaqtedr4dekq08ge8ztwac72sfr9rusxg3297'
     # }

     # 生成指定格式
     p2pkh_addr = gen.generate_p2pkh_address(private_key)
     p2sh_addr = gen.generate_p2sh_address(private_key)

     # 检测地址格式
     fmt = gen.detect_address_format("1A1z...")
     print(fmt)  # AddressFormat.P2PKH
     ```

2. FormatAwareTargetManager (格式感知目标管理器)
   位置: src/collision/targets/format_aware_manager.py

   功能:
     - 自动检测目标地址格式
     - 按格式分组管理目标
     - 格式感知匹配
     - 批量加载

   示例:
     ```python
     from src.collision.targets.format_aware_manager import FormatAwareTargetManager

     manager = FormatAwareTargetManager()

     # 添加多格式目标
     manager.add_target("1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa")  # P2PKH
     manager.add_target("3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy")  # P2SH
     manager.add_target("bc1qw508d6qejxtdg4y5r3zarvary0c5xw7kv8f3t4")  # Bech32
     manager.add_target("bc1p5d7rjq7g6rdk2yhzks9smlaqtedr4dekq08ge8ztwac72sfr9rusxg3297")  # Taproot

     # 获取统计
     stats = manager.get_format_stats()
     print(stats)
     # {'p2pkh': 1, 'p2sh': 1, 'bech32': 1, 'taproot': 1}

     # 检查匹配
     is_match, matched_addr, matched_fmt = manager.check_match(private_key)
     if is_match:
         print(f"Matched {matched_fmt} address: {matched_addr}")

     # 从文件加载
     manager.load_from_file("targets.txt")
     ```

三、使用方法
================================================================================

方法1: 独立使用多格式生成器
  ```python
  from src.core.multi_format_generator import MultiFormatAddressGenerator

  gen = MultiFormatAddressGenerator()

  # 生成地址
  private_key = secrets.token_bytes(32)
  addresses = gen.generate_all_formats(private_key)

  # 检查是否匹配目标
  targets = {
      "1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa",
      "3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy",
      "bc1qw508d6qejxtdg4y5r3zarvary0c5xw7kv8f3t4",
  }

  for fmt, addr in addresses.items():
      if addr.lower() in [t.lower() for t in targets]:
          print(f"Found match in {fmt}: {addr}")
  ```

方法2: 使用格式感知管理器
  ```python
  from src.collision.targets.format_aware_manager import FormatAwareTargetManager

  manager = FormatAwareTargetManager()
  manager.load_from_file("multi_format_targets.txt")

  # 检查所有格式匹配
  private_key = secrets.token_bytes(32)
  is_match, matched_addr, matched_fmt = manager.check_match(private_key)

  if is_match:
      print(f"Matched {matched_fmt} address: {matched_addr}")
  ```

方法3: 批量处理
  ```python
  from src.collision.targets.format_aware_manager import FormatAwareTargetManager

  manager = FormatAwareTargetManager()
  manager.load_from_file("targets.txt")

  stats = manager.get_format_stats()
  print(f"Total targets: {len(manager)}")
  print(f"Format distribution: {stats}")

  # 获取按格式分组的目标
  targets_by_format = manager.get_targets_by_format()
  for fmt, targets in targets_by_format.items():
      print(f"{fmt.value}: {len(targets)} targets")
  ```

五、技术细节
================================================================================

地址格式对比:

| 格式 | 前缀 | 版本 | 哈希 | 编码 | Witness |
|------|------|------|------|------|---------|
| P2PKH | 1 | 0x00 | RIPEMD160(SHA256(pubkey)) | Base58Check | No |
| P2SH | 3 | 0x05 | RIPEMD160(SHA256(redeem_script)) | Base58Check | No |
| Bech32 | bc1q | 0 | RIPEMD160(SHA256(pubkey)) | Bech32 | v0 |
| Taproot | bc1p | 1 | xonly_pubkey | Bech32m | v1 |

生成流程:
  1. P2PKH: pubkey → SHA256 → RIPEMD160 → Base58Check(0x00 + hash)
  2. P2SH: redeem_script → SHA256 → RIPEMD160 → Base58Check(0x05 + hash)
  3. Bech32: pubkey_hash → witness_program → Bech32(hrp, 0, program)
  4. Taproot: xonly_pubkey → witness_program → Bech32m(hrp, 1, program)

================================================================================
九、限制和注意事项
================================================================================

1. Taproot支持
   - 需要coincurve库
   - 使用xonly公钥 (32字节)
   - Bech32m编码

2. 格式兼容性
   - 同一个公钥生成不同格式地址完全不同
   - 无法从地址反推其他格式地址
   - 必须为每个格式单独匹配

3. 性能影响
   - 生成4种格式比单格式慢约4倍
   - 可按需启用格式
   - 使用格式统计优化
