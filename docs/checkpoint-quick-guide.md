# 断点续传功能 - 快速使用指南

## 🎯 核心功能

### 1️⃣ 断点续传复选框
**作用**: 启用后自动保存对撞进度

**使用步骤**:
```
1. 勾选"断点续传" ✓
2. 开始对撞
3. 系统每30秒自动保存
4. 停止后可恢复
```

### 2️⃣ 恢复断点按钮
**作用**: 从上次保存的进度继续对撞

**使用步骤**:
```
1. 点击"恢复断点"
2. 查看断点信息
3. 确认恢复
4. 继续对撞
```

### 3️⃣ 断点状态显示
**位置**: 恢复断点按钮右侧

**状态说明**:
- `✓ 断点: 8,126,464 (random)` 🟢 - 有有效断点
- `✗ 断点文件无效` 🔴 - 断点文件损坏
- `无断点` 🔵 - 没有断点文件

## 📋 常见场景

### 场景A: 计划性暂停
```
对撞中 → 勾选断点续传 → 点击停止 → 下次恢复
```

### 场景B: 意外中断
```
程序关闭 → 重新启动 → 点击恢复断点 → 继续
```

### 场景C: 新对撞任务
```
修改目标 → 勾选断点续传 → 开始对撞 → 选择"否"覆盖断点
```

## ⚡ 快捷操作

| 操作 | 步骤 |
|------|------|
| 启用断点 | 勾选"断点续传"复选框 |
| 恢复进度 | 点击"恢复断点"按钮 |
| 查看状态 | 看按钮右侧的状态文字 |
| 开始新任务 | 不勾选断点续传，或直接开始 |

## ⚠️ 重要提示

1. **自动保存**: 启用后每30秒自动保存
2. **数据安全**: 断点文件不包含私钥
3. **文件位置**: `src/collision/collision_checkpoint.json`
4. **恢复时机**: 随时可以点击"恢复断点"

## 🆘 故障排除

| 问题 | 解决方法 |
|------|----------|
| 未找到断点文件 | 开始新对撞并启用断点续传 |
| 断点加载失败 | 删除断点文件，重新开始 |
| 状态显示异常 | 点击"恢复断点"刷新 |

## 📊 断点文件内容

```json
{
  "mode": "random",           // 对撞模式
  "total_checked": 8126464,   // 已检测数量
  "targets": [...],           // 目标地址
  "timestamp": "..."          // 保存时间
}
```

**注意**: 不包含私钥等敏感信息 ✓

---

💡 **提示**: 对于长时间对撞任务，建议始终启用断点续传功能！
