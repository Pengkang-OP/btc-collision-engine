[Examples] 使用示例
================================================================

1. 快速模式 (推荐新手)
   使用默认配置直接启动（需要targets.txt文件）
   $ python key_collision_cli.py --quick-run

2. 基础随机碰撞
   最简单的使用方式，持续运行直到 Ctrl+C
   $ python key_collision_cli.py -t 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa -m random

3. 断点续传（推荐）
   启用断点续传和去重，运行1小时后自动停止
   $ python key_collision_cli.py -t 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa -m random --checkpoint --dedup --duration 3600

4. 从文件加载目标
   从文件读取多个目标地址
   $ python key_collision_cli.py -f targets.txt -m random --checkpoint

5. GPU加速模式
   启用单GPU加速（速度提升数千倍）
   $ python key_collision_cli.py -t 1A1zP1...DivfNa -m random --use-gpu

6. 多GPU模式
   使用所有可用GPU设备
   $ python key_collision_cli.py -f targets.txt -m random --multi-gpu

7. 范围扫描
   在指定私钥范围内搜索
   $ python key_collision_cli.py -t 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa -m range --start 1 --end FFFFFFFF

8. 交互式向导
   逐步引导配置，适合新手
   $ python key_collision_cli.py --quick-start

9. 系统健康检查
   检查系统依赖和配置状态
   $ python key_collision_cli.py --health-check

10. 验证地址文件
   批量验证文件中的地址格式
   $ python key_collision_cli.py --validate-addresses targets.txt

================================================================
[TIP] 使用提示:
   - 新手推荐运行 python key_collision_cli.py --quick-start 进入向导
   - 运行 python key_collision_cli.py --help 查看所有选项
   - 运行 python key_collision_cli.py --config-check 验证配置

----------------------------------------------------------------
[快捷命令别名]
   qs      = --quick-start  (交互式向导)
   qr      = --quick-run    (快速模式)
   hc      = --health-check (健康检查)
   cc      = --config-check (配置验证)
   ex      = --examples     (显示示例)
   rec     = --recommend    (参数推荐)
