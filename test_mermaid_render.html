📊 GPU 碰撞引擎完整操作流程图

流程图说明

本流程图展示了比特币碰撞引擎 GPU 模式的完整操作流程，包含四个主要步骤：

  1. 导入 WIF 地址表 - 加载、验证、转换目标地址
  2. 选择 GPU 模式 - 扫描设备、配置参数
  3. 选择 GPU 设备 - 设备列表、性能评分、初始化
  4. 启动地址比对 - 碰撞计算、实时监控、结果处理
